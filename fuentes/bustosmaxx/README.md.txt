# Predicción de Churn

Este repositorio documenta una actividad académica centrada en la optimización de hiperparámetros de LightGBM mediante Bayesian Optimization, con foco en la mejora de un problema de marketing de retención proactiva de clientes.


## 1. Estructura del repositorio

```text
├── README.md
├── notebook/
│   └── DMEyF___1er_competencia.ipynb
├── src/

│   └── numeros_primos.py
├── data/
├── logs/
├── output/
├── _targets.R
├── datamining_ecoyfin.Rproj
├── Diccionario.xlsx
├── LICENSE
└── .gitignore
```

## 2. Enfoque metodológico

La notebook y el proyecto buscan llegar a una solución completa de la competencia, con:

- preprocesamiento del dataset,
- entrenamiento de un modelo LightGBM,
- ajuste de hiperparámetros mediante optimización bayesiana,
- evaluación de la calidad del modelo y de la ganancia de negocio,
- generación de salidas para análisis posterior.
