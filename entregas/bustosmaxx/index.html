Resumen

El repositorio contiene un notebook de R (`notebook/DMEyF___1er_competencia.ipynb`, titulado 'Tarea para el Hogar 04'), un pipeline del paquete targets (`_targets.R` y `src/optimizacion_hiperparamentros.R`) que repite como funciones la parte de búsqueda de hiperparámetros, un script de Python que lista números primos, un README y una carpeta `output/` con un PDF, un CSV y un archivo de Power BI sobre clusters de clientes BAJA+2. El camino que llega a una predicción de 202108 está en el notebook: descarga el dataset crudo, calcula clase_ternaria, agrega lags y deltas de orden 1 y 2 de 152 variables, divide cada columna por su máximo absoluto y guarda el resultado. Después corre una optimización bayesiana (mlrMBO, 30 iteraciones) de tres hiperparámetros de LightGBM, con AUC en validación cruzada de 5 folds sobre 202103-202104 y el 10% de los CONTINUA. Entrena con 202103-202106 sin submuestreo y clase binaria BAJA+1 o BAJA+2, imprime la ganancia sobre 202106 para cortes de 4.000 a 19.000 envíos y, en la última celda, entrena un modelo por cada una de 16 semillas, predice 202108 y promedia por cliente la probabilidad de 20 archivos de predicción en `prediccion_final_20sem.txt`.

Qué entrega. El notebook termina escribiendo `prediccion_final_20sem.txt` (separado por tabuladores) con `numero_de_cliente` y `probabilidad_promedio` para los clientes de 202108. No se observa en el código la generación de un archivo con la lista de clientes a enviar. El repositorio no incluye `prediccion_final_20sem.txt` ni los demás archivos que escribe el notebook.

Cómo se ejecuta. El README no indica cómo ejecutarlo. Las celdas de texto del notebook dicen que la primera parte (montaje de Google Drive y descarga del dataset) se corre con runtime Python 3 y el resto con runtime R. `_targets.R` define un pipeline de targets de tres pasos; ningún texto indica cómo lanzarlo.

246rankear_cero_fijo <- function(x) {
247 out <- rep(0, length(x))
248 pos <- which(!is.na(x) & x > 0); neg <- which(!is.na(x) & x < 0)
249 if (length(pos) == 1) out[pos] <- 1 else if (length(pos) > 1) out[pos] <- frank(x[pos], ties.method = "average") / length(pos)
250 if (length(neg) == 1) out[neg] <- -1 else if (length(neg) > 1) out[neg] <- -(length(neg) - frank(x[neg], ties.method = "average") + 1) / length(neg)
